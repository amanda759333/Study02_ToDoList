# Study02_ToDoList

하루 10~20개의 할 일을 관리하는 개인용 할 일 관리 웹 앱입니다.
설치나 서버 없이 브라우저에서 바로 열어 쓰고, 새로고침해도 데이터가 유지됩니다.

> **현재 상태: 첫 버전(MVP) 구현 완료.** PRD의 P0 기능(4.1~4.7)을 모두 구현했습니다.
> 아직 확인하지 못한 항목은 아래 [확인 현황](#확인-현황)에 정리했습니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 설치와 빌드가 필요 없습니다.

```bash
python -m http.server 8000
```

위처럼 로컬 서버로 열어도 됩니다(http://localhost:8000). 데이터는 열어 본 주소(origin)별로
브라우저 `localStorage`에 저장되므로, 항상 같은 방식으로 여는 것을 권장합니다.

## 주요 기능

- 할 일 추가 (Enter 또는 [추가] 버튼) · 수정 (더블클릭 또는 [수정] 버튼, Enter 저장, Esc 취소) · 삭제 (확인 창)
- 완료 체크 (취소선 표시)
- 카테고리 분류 (업무 / 개인 / 공부)와 항목 수가 표시되는 필터 탭
- 전체·카테고리별 진행률 (필터와 상관없이 전체 기준)
- `localStorage` 저장으로 새로고침 후에도 데이터와 선택한 필터 유지

## 기술

- 순수 JavaScript (프레임워크·빌드 도구·외부 라이브러리 없음)
- `index.html` + `style.css` + `app.js` 세 파일
- 사용자 입력은 `textContent`로만 화면에 넣음 (`innerHTML` 미사용)
