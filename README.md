# Study02_ToDoList

하루 10~20개의 할 일을 관리하는 개인용 할 일 관리 웹 앱입니다.
설치나 서버 없이 브라우저에서 바로 열어 쓰고, 새로고침해도 데이터가 유지되는 것을 목표로 합니다.

> **현재 상태: 기획 단계.** 아직 앱 코드는 없고, 요구사항 문서([PRD.md](PRD.md))만 있습니다.

## 주요 기능

- 할 일 추가 · 수정 · 삭제
- 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)와 카테고리별 필터
- 전체·카테고리별 진행률 보기
- 브라우저 `localStorage` 저장으로 새로고침 후에도 데이터 유지

## 기술 방향

- 순수 JavaScript (프레임워크·빌드 도구·외부 라이브러리 없음)
- `index.html` + `style.css` + `app.js` 세 파일 구성 (예정)
- `index.html`을 브라우저로 열기만 하면 동작

## 문서

- [PRD.md](PRD.md): 목표, 데이터 모델, 기능 요구사항, 화면 구성, 성공 기준
